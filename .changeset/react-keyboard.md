Add `@play-ui/react-keyboard`: a headless drawn keyboard that lights the keys a shortcut presses, with the state for a searchable shortcut sheet. Layouts (`qwertyUS`, `qwertyUK`, `qwertyInternational`) and platforms (`mac`, `pc`) are separate exports, composed with `createBoard`, so a bundle keeps only the ones it imports.
