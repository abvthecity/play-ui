# @play-ui/react-deck

## 0.1.0

### Minor Changes

- [`870dc1a`](https://github.com/abvthecity/play-ui/commit/870dc1a1f2fb90068eff153253bf722d995e2a98) Thanks [@claude](https://github.com/claude)! - Add `@play-ui/react-deck`: a headless deck of index cards. Put away it is a pile; dealt, its top card flies out into a folder with a tab per facet, each tab flips the folder to its facet, and the put-away tucks the tabs in before the folder shrinks back onto the pile. As a `"sheet"` the same facets are a modal dialog that rises from the foot of the screen and closes on a swipe down. The parts own the flights (Web Animations on springs from `@play-ui/physics`), the tab list, the keys and the dialog, and ship no styles.
